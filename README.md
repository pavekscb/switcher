# Switcher — автопереключатель раскладки для Windows

Лёгкий аналог Punto Switcher на Python. Работает в трее, сам замечает слово, набранное не в той раскладке (`ghbdtn` вместо `привет`), и исправляет его на лету.

## Возможности

- Автоисправление слов RU ↔ EN после нажатия пробела или Tab
- Ручное исправление последнего слова клавишей **Pause/Break** (повторное нажатие возвращает всё обратно)
- Сохраняет регистр (`Ghbdtn` → `Привет`)
- Работает и с короткими словами (`yt` → `не`, `yf` → `на`), но с более строгими порогами
- Тихий щелчок при исправлении (можно отключить)
- Иконка в трее: вкл/выкл автоисправления, звук, автозапуск с Windows, ссылка на проект
- Настройки запоминаются между запусками
- Всё работает офлайн, в сеть ничего не отправляется

## Быстрый старт (из исходников)

Нужен Python 3.10+ для Windows.

```
pip install keyboard pystray pillow wordfreq
python switcher.py
```

В трее появится зелёная иконка **Aя**. Выход: правый клик по иконке → «Выход».

## Как собрать exe самостоятельно

Готовый `.exe` не требует установленного Python.

**Вариант 1: одним файлом**

1. Скачайте репозиторий и откройте папку с файлами `switcher.py`, `layout.py`, `detector.py`, `build.bat`
2. Запустите `build.bat` (двойной клик)
3. Готовый файл появится в `dist\LayoutSwitcher.exe`

**Вариант 2: вручную в командной строке**

```
cd /d путь\к\папке\switcher
python -m pip install pyinstaller pystray pillow keyboard wordfreq
python -m PyInstaller --noconsole --onefile --clean --name LayoutSwitcher --collect-data wordfreq --collect-data langcodes switcher.py
```

Пояснения к параметрам:

| Параметр | Зачем |
|---|---|
| `--noconsole` | без окна консоли, только иконка в трее |
| `--onefile` | один exe-файл |
| `--collect-data wordfreq` | упаковать словари частотности слов (без них автодетект не работает) |
| `--collect-data langcodes` | данные для библиотеки языков, от которой зависит `wordfreq` |

Заметки:

- Используйте `python -m PyInstaller`, а не просто `pyinstaller`: папка Scripts часто не добавлена в PATH
- Размер exe 60–70 МБ, это в основном словари
- Антивирус может ругаться на exe: любая программа с глобальным перехватом клавиатуры похожа на кейлоггер. Исходный код открыт, можно собрать самому
- Для автозапуска достаточно включить пункт в меню трея, он сам пропишет путь к exe в реестр (`HKCU\...\Run`)

## Как пользоваться

| Действие | Что делает |
|---|---|
| Набрать слово не в той раскладке и нажать пробел | слово исправится само |
| **Pause/Break** | исправить последнее слово вручную (или вернуть обратно) |
| Левый клик по иконке в трее | включить/выключить автоисправление (иконка станет серой) |
| Правый клик по иконке | звук, автозапуск, ссылка на проект, выход |

Окна, запущенные от имени администратора, не исправляются, пока сам Switcher не запущен от администратора (правый клик по exe → «Запуск от имени администратора»).

## Принцип работы

1. **Перехват клавиш.** Библиотека `keyboard` ставит глобальный хук Windows (`WH_KEYBOARD_LL`) и сообщает о каждом нажатии.
2. **Буфер слова.** Скрипт накапливает символы текущего слова. Пробел и Tab завершают слово, Backspace удаляет последний символ, Ctrl/Alt/Win-комбинации, стрелки и Enter сбрасывают буфер.
3. **Какой символ получило окно.** Символ берётся не из имени клавиши, а вычисляется по физическому scan-коду через `ToUnicodeEx` в раскладке окна, куда идёт ввод (`GetGUIThreadInfo` → `GetKeyboardLayout`). Так исправление не зависит от того, какую раскладку «видит» сам скрипт.
4. **Конвертер.** `layout.py` содержит таблицу соответствия QWERTY ↔ ЙЦУКЕН (с Shift и символами `Ё`, `№`, `"` и т.д.).
5. **Детектор** (`detector.py`). Слово исправляется, если оно не похоже на нормальное в своей раскладке, а в другой раскладке это частое слово. Частоты берутся из `wordfreq` (русский, английский, украинский):
   - обычные слова: слово в другой раскладке должно быть частым (`TARGET_MIN`) и заметно частотнее исходного (`GAP`)
   - двухбуквенные слова: строже (`SHORT_TARGET_MIN`, `SHORT_GAP`), чтобы не ломать английские аббревиатуры
   - длинные (6+ букв) слова, которых нет в словаре, допускают более редкий результат (`RARE_TARGET_MIN`), это помогает с техническими терминами
   - клавиши `` ` [ ] ; `` не бывают в обычном английском слове, поэтому такое слово считается неизвестным
6. **Исправление.** В отдельном потоке: Backspace × длина слова (и пробела), переключение раскладки окна (`WM_INPUTLANGCHANGEREQUEST`), ввод правильного текста юникод-событиями (`keyboard.write`). Пока идёт исправление, собственные нажатия игнорируются (флаг `busy`).
7. **Защиты.** Проверка слова идёт не в хуке (иначе Windows отключает медленный хук) и отменяется, если пользователь уже начал печатать следующее слово. Второй экземпляр программы не запустится (mutex).

## Файлы проекта

| Файл | Назначение |
|---|---|
| `switcher.py` | хук клавиатуры, исправление, трей, звук, автозапуск, настройки |
| `layout.py` | конвертер раскладок EN ↔ RU |
| `detector.py` | решение «слово набрано не в той раскладке» по словарям |
| `build.bat` | сборка `LayoutSwitcher.exe` |

Настройки хранятся в `%APPDATA%\LayoutSwitcher\settings.json`, ошибки (только в режиме exe) — в `%APPDATA%\LayoutSwitcher\errors.log`.

## Настройка

- **Pause → другая клавиша:** переменная `HOTKEY` в `switcher.py` (например, `"scroll lock"`)
- **Громкость щелчка:** `CLICK_VOLUME` в `switcher.py`
- **Чувствительность автодетекта:** константы в начале `detector.py`. Если слова исправляются зря, увеличьте `TARGET_MIN` или `GAP`; если не исправляются, уменьшите

## Ограничения

- Поддерживаются только раскладки EN (США) и RU (ЙЦУКЕН); украинские слова распознаются как «нормальные» и не трогаются, но не конвертируются
- Автоисправление срабатывает только после пробела или Tab; знаки препинания, набранные вплотную к слову, считаются его частью
- Поля паролей не исключаются; слова не сохраняются и не передаются, но в режиме с консолью (`python switcher.py`) введённые слова выводятся в консоль для отладки
- Если печатать очень быстро в момент исправления, часть символов может потеряться
- Проверено на Windows 10

## Приватность

Программа работает полностью локально: слова никуда не отправляются и не сохраняются. Собранный exe (`--noconsole`) отбрасывает отладочный вывод со словами.
